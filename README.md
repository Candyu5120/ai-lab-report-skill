# 人工智能实验报告 Skill

根据参考 Word 版式快速编写人工智能及计算机课程实验报告。

## 在线安装

在 Codex 中发送下面这句话：

```text
使用 $skill-installer 安装这个 Skill：https://github.com/Candyu5120/ai-lab-report-skill/tree/main/skills/artifact-template-ai-lab-report
```

安装后下一轮即可使用；若未显示，请重启 Codex。生成 Word 报告时，需要环境具备 Documents 技能或等效的 Word 编辑和渲染能力。

## 使用

```text
使用 $artifact-template-ai-lab-report，根据以下实验题目、代码和运行记录编写 Word 实验报告：……
```

## 固定格式

- 编号层次：一、 → 1. → （1） → ①。
- 流程图：Visio 基本样式，白底黑线，连接线仅直线或零圆角直角折线，无曲线。
- 六个章节：实验目的、实验原理、实验过程、实验结果、问题与解决方法、实验心得。
- 参考版式：A4，宋体正文，首页信息表，居中页码。
- 不虚构实验数据、运行截图或已完成的操作。

本仓库参考文档为分享副本，个人信息已替换为占位符，原始截图和文档作者元数据已移除；预览图由该分享副本生成。
